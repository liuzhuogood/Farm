# 测试避坑指南

macOS 远程测试不要用 SSH 直接执行 `screencapture`（会报 `could not create image from display`），改用 `ssh 10.0.0.11 'osascript -e "tell application \"Terminal\" to do script \"screencapture -x /tmp/shot.png\""'` 交给登录桌面的 Terminal 截图，再确认文件已生成。

若截图只拍到壁纸，先确认显示器已唤醒（`caffeinate -u -t 5` 后重拍）；若确实抓不到内容，用 `ssh <host> 'sudo launchctl asuser <uid> sudo -u <user> /usr/sbin/screencapture -x /tmp/shot.png'` 在图形会话内截图。AppleScript 驱动 Terminal 会被 TCC 自动化授权挂住（`osascript` 不返回、退出码 142），改用 `open -a Terminal <script.sh>` 触发截图脚本，卡住的授权弹窗用 `killall tccd` 收掉。

Mac mini 桌面服务端口每次启动可能变化，读 `~/Library/Application Support/com.farm.desktop/desktop-endpoint.json` 取端口，令牌取同目录最新的 `desktop-ready-<pid>.json`，以 `Authorization: Bearer <token>` 访问 `/api/desktop/*`；直接请求会返回 `unauthorized`，不要假定 8080。

Windows 11 测试机（`test@10.0.0.119`）RDP 会话断开后，登录会话里截屏会报「句柄无效」，先用 `ssh test@10.0.0.119 'tscon 1 /dest:console'` 把 `test` 会话切到控制台，再截图。

需要桌面、鼠标或截屏的 PowerShell 不能直接跑在 SSH 会话里，用 `New-ScheduledTaskPrincipal -LogonType Interactive`（用户 SID `S-1-5-21-3051550688-947349123-1589891005-1000`）注册计划任务再 `Start-ScheduledTask`，脚本在登录会话里执行。

给 Windows 测试机传的 `.ps1` 必须存成 UTF-8 with BOM，否则 PowerShell 5.1 按 GBK 解析，脚本里的中文参数会变成 `check 璁剧疆` 这类乱码；跨 SSH 调 PowerShell 也不要套多层 `-Command "…"` 引号，先 `scp` 到测试机再用 `-File` 执行。

设备列表首页点击设备卡片是「打开小窗」，不是点击设备；要在设备上真正操作，点小窗或详情页里的镜像画面（截图里用像素定位画面区域再换算设备坐标）。

Windows 上要精确验证浏览器界面，别靠像素坐标点窗口：给 Edge 加 `--remote-debugging-port=9222 --remote-allow-origins=* --user-data-dir=<独立目录> --app=<url>`（端口只绑 127.0.0.1），本机用 `ssh -L 19222:127.0.0.1:9222 test@<测试机>` 转发，再用 CDP 的 `Input.dispatchMouseEvent` / `Runtime.evaluate` / `Page.captureScreenshot` 点击、取值与截图。
