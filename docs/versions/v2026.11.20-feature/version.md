# v2026.11.20：更新通道（正式版 / beta）

## 1. 版本定位与概述

在 `v2026.11.19` 基线上，给 Farm 增加可选更新通道：默认正式版，可切换到 beta 测试版，用于日常开发测试。beta 覆盖桌面 App、五平台 CLI、Windows GUI 与服务器二进制；正式用户零影响。同时把 `farm-sdk` 从「跟随应用版本发布」改为「SDK 有改动才发」。

- 设计文档：[docs/designs/2026-11-20-update-channels.md](../../designs/2026-11-20-update-channels.md)
- 实施跟踪：[tasks.md](tasks.md)

## 2. 已确认的决定

| 项 | 结论 |
| --- | --- |
| beta 范围 | 全部发布形态，含服务器 CLI 二进制 |
| 签名 | 沿用现有 Tauri 更新私钥，不新建 beta 密钥 |
| PyPI | 改成按需发布：`farm-sdk` 无改动不发新版本 |
| 通道存储 | 后端配置一份，Web 与桌面共用 |
| 桌面 endpoint | 由后端解析后下发，Rust 不重复实现 GitHub 解析 |
| 服务器 beta | 同机 8081 独立实例 `farm-beta.service` + 独立数据目录 |

## 3. 范围

S1–S6：版本比较与通道后端、桌面与前端通道接入、beta 发布流水线、服务器 beta 实例与部署脚本、SDK 独立版本与按需发布、文档与术语登记。

不包含：灰度百分比、alpha/nightly 通道、按设备分组的通道策略。

## 4. 验收

按设计文档第 6 节 T1–T7 执行。T5（服务器 beta）、T2/T3（beta 安装与回退）必须在 10.0.0.6 与真实客户端上验，不以命令退出码代替。
