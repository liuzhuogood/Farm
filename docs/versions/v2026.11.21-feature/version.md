# v2026.11.21：左侧菜单、任务记录与独立设置页

## 1. 版本定位与概述

在 `v2026.11.20` 的更新通道基线上，重构主窗口导航：移除顶部操作栏，新增可收起的左侧菜单，并补齐全设备任务记录、API 入口和独立设置页。依赖页改为骨架屏加载与即时生效，不再需要保存按钮。

- 设计文档：[docs/designs/2026-11-21-app-shell-navigation.md](../../designs/2026-11-21-app-shell-navigation.md)
- 实施跟踪：[tasks.md](tasks.md)

## 2. 已确认的决定

| 项 | 结论 |
| --- | --- |
| 左侧菜单 | 设备列表、任务记录、AI 集成、API；底部设置可展开 |
| 设置页 | 通用设置（含投屏）、服务、依赖，各自独立路由 |
| 设置底部操作 | 恢复所有小窗、重启 ADB 服务 |
| 任务记录 | 全设备只读汇总，详情懒加载，不改变单设备任务接口 |
| 依赖保存 | 修改即自动保存，移除手动保存按钮 |
| 发布 | 本次走 beta 预发布，供 Mac mini 测试使用 |

## 3. 范围

- S1 版本与设计记录
- S2 全设备任务记录后端接口与测试
- S3 左侧菜单、路由与页面骨架
- S4 设置页拆分与依赖即时保存
- S5 桌面快捷操作与文档登记
- S6 构建、Mac mini 自测与 beta 发布
- S6 附加修复：生产二进制为 Vue 子路由提供 `index.html` 回退

不包含：任务删除/归档、设置权限、移动端独立布局。

## 4. 验收

按设计文档第 5 节 1–7 项执行；界面交互以 Mac mini 浏览器实测为准，beta 发布后核对 Release 标记与更新通道。
